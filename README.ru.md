## Что умеет программа

### Добавление игр в Steam

Добавление в библиотеку Steam сторонних (Non-Steam) игр с автоматическим определением названия, EXE-файла, удобным выбором официальных параметров запуска (или вводом своих) и полным набором обложек из двух источников: Steam и SteamGridDB. Можно добавлять игры по одной через карточку или пакетно: всё, в чём программа уверена, заполняется автоматически, а недостающее она уточняет у вас.

Встроенная база названий игр Steam нужна для более точного поиска. Она содержит данные об играх на момент создания программы; для точного поиска новинок рекомендуется получить свой Steam Web API-ключ и указать его в настройках.

Из карточки игру можно сразу запустить кнопкой **Запуск**: она стартует ровно то, что показано в карточке (выбранный EXE или эмулятор, ROM, параметры запуска), даже если игра ещё не сохранена.

### Обложки: Steam, SteamGridDB и анимация

- **Два источника** — официальные обложки Steam (с выбором региона) и пользовательские из SteamGridDB, для четырёх слотов: вертикальная, горизонтальная, фон (hero) и логотип, плюс иконка.
- **Анимированные обложки.** Поддерживаются GIF, APNG и анимированный WebP: анимация играет в карточке, в плитках Library и в окне выбора SteamGridDB. Файл обложки при этом не меняется и передаётся Steam как есть (анимированные файлы сохраняются в `config\grid` под именем `.png`, так их понимает Steam). Для WebP программа один раз скачивает утилиты libwebp.
- **Окно выбора SteamGridDB.** Порядок «по популярности» совпадает с сайтом steamgriddb.com. Сортировка: по рейтингу, сначала новые, сначала старые, а для ROM — сначала обложки нужной платформы. Фильтры как на сайте: размеры, стили, языки, тип файла, теги (статичные, анимированные, юмор, 18+, эпилепсия). Варианты подгружаются по мере прокрутки, миниатюры скачиваются в фоне с повторами при сбоях. Под плитками показаны значки: анимированная обложка, комментарий автора (текст в подсказке) и число лайков.
- **Свои картинки.** Плитка «Выбрать свою» принимает PNG, JPG, GIF, APNG, WebP, ICO и другие форматы; иконки EXE игры предлагаются автоматически.
- **Логотип как в Steam.** Позиция и размер логотипа берутся у разработчика игры, а при ручной настройке логотип прилипает к пяти позициям Steam (с подсказками при перетаскивании). Кнопка обрамления показывает фон так, как его рисует клиент Steam.
- **Быстрая загрузка.** Из зеркал Steam CDN (akamai, fastly, cloudflare) автоматически выбирается самое быстрое, четыре обложки скачиваются параллельно.

### Импорт из лаунчеров

Epic Games, GOG Galaxy, Ubisoft Connect, EA App, Battle.net, Xbox. Импорт отмеченных игр в Steam (ручной и автоматический); выбор можно набирать сразу из нескольких лаунчеров и импортировать одной кнопкой. Обложки настраиваются так же, как у обычных игр. Для запуска используется собственный тихий лаунчер: он следит, чтобы сторонний лаунчер стартовал в тихом режиме, переводит фокус на игру и закрывает сторонний лаунчер после выхода из игры. Ощущение такое, будто вы играете в обычную игру из Steam.

### Автоматический импорт

Для тех, кто экономит время: при включённой опции автоимпорта игры добавляются большими пачками и очень быстро, без вашего участия. От вас потребуется только уточнить данные, которые программа не смогла определить с уверенностью. Пример с обычными играми показан на гифке в разделе «Добавление игр в Steam».

### Сохранения игр: резервные копии и восстановление

- **Поиск сохранений без запуска игры.** Пути берутся из официальной базы Ludusavi (лицензия MIT, встроена в программу, обновляется из настроек), из известных путей эмуляторов Steam (в том числе для не лицензионных копий игр), из Steam Cloud и по эвристике. Для игр, которых нет в базе, есть детектор: он запускает игру, следит за создаваемыми файлами и предлагает наиболее вероятные папки.
- **Резервное копирование и восстановление** — для одной игры (кнопки в карточке и пункты меню плитки) или для всех отмеченных игр сразу (кнопки **Сохранения** в главном окне и в окне Library). Копии хранятся в zip-архивах; если сохранения не менялись, новый архив не создаётся. Перед восстановлением текущие сохранения автоматически откладываются в страховочный архив `pre-restore`, а если копий несколько, можно выбрать нужную.
- **Сначала выбор действия.** Кнопки *Сохранения* можно нажать и без отмеченных игр: выбранное действие (поиск, бэкап, восстановление) определяет, какие игры можно отметить, а файловые панели показывают результат в колонке *Наличие* / *Бэкап* (найдены / не найдены или дата последней копии).
- Общая папка резервных копий выбирается в настройках. ROM-ы в этой функции не участвуют.

### Добавление ROM-ов с выбором эмулятора

Панели показывают папки и ROM-файлы по расширениям активного эмулятора. Менеджер эмуляторов, поддержка RetroArch с выбором ядра, архивы (zip, 7z, rar и др.) с распаковкой во временную папку, свои параметры запуска эмуляторов (например, полноэкранный режим). При изменении профиля эмулятора программа находит все использующие его ярлыки и предлагает обновить их разом. Эмулятор уже добавленных ROM-ов можно сменить в Library одним действием, не открывая карточку, а обложки SteamGridDB для ROM-ов подбираются с учётом платформы.

- **Готовые пресеты** эмуляторов с параметрами запуска (DuckStation, PPSSPP, mGBA, Mesen, MAME, Xenia, Ryujinx и другие, платформа DOS с DOSBox / DOSBox-X / DOSBox Staging).
- **Ядра RetroArch.** При выборе ROM учитываются расширения, которые ядро действительно открывает: остальные файлы уходят в конец списка и не выбираются автоматически (в том числе внутри архивов).
- **Многодисковые игры (m3u).** В профиле эмулятора включается галочка *Multi-disc (m3u)* (для RetroArch, DuckStation, Mednafen, Flycast и BizHawk она включена по умолчанию). Диски вида `(Disc 1)`, `[CD2]` находятся автоматически и добавляются одной записью. В карточке окно *Диски...* позволяет собрать или поправить список вручную (добавить, убрать, изменить порядок). Файлы m3u хранятся в `%APPDATA%\Steam Commander\m3u`, в папку с ROM-ами ничего не пишется, а при перемещении дисков пути в m3u обновляются.

### Врапперы запуска

Врапперы позволяют запускать обычную игру через вспомогательную программу: Virtual Desktop Streamer, Sandboxie, Locale Emulator, режимы совместимости, высокий приоритет и т. п. В ярлыке Steam запускаемым файлом становится враппер, а аргументы строятся по шаблону (`{game}` — путь к игре, `{args}` — ваши параметры запуска из карточки). Врапперы настраиваются в **Настройках**, в разделе *Врапперы*: там есть список готовых пресетов, а свои можно добавить и отредактировать.

- **Карточка.** Галочка с выпадающим списком врапперов справа от параметров запуска; выбор сохраняется в ярлыке и восстанавливается при повторном открытии.
- **Главное окно.** Переключатель *Wrappers* под *ROMs* (включён может быть только один из двух): добавляемые игры идут через активный враппер, а уже добавленные отмеченные игры можно перевести на него.
- **Library.** Категория *Врапперы* в фильтре с отдельной галочкой на каждый враппер, а по правой кнопке доступны *Сменить враппер* и *Убрать враппер* для одной или всех отмеченных игр. ROM-ы и игры из лаунчеров (`SCLauncher.exe`) не затрагиваются; иконка игры берётся у самой игры, а не у враппера.

### Обновление и управление библиотеками апскейлеров

Скачивание и выбор версий DLSS / FSR / XeSS / XeLL. Замена библиотек в выбранных играх (или во всех добавленных) одной кнопкой, по желанию автоматически при добавлении игры в Steam. По итогам операции показывается подробный отчёт по каждой игре. Оригиналы сохраняются как `.sc_orig`, восстановление одним действием. Кнопки *Библиотеки* есть в главном окне и в окне Library и работают по отмеченным играм: обновить можно только игры с библиотеками апскейлеров, вернуть оригиналы — только игры с сохранёнными оригиналами, а колонка *DLSS* в панелях показывает версию `nvngx_dlss.dll`.

### Двухпанельный браузер

Две независимые панели (любые папки и диски). Поиск, сортировка, размер папок, отметка «уже в Steam» со значком игры. Перемещение папок игр и ROM-ов между панелями с прогрессом и автоматическим обновлением ярлыков Steam. Умное перемещение сразу в обе стороны между папками и дисками: отметьте игры на обеих панелях и нажмите пробел, чтобы узнать, возможно ли такое перемещение и сколько места не хватает.

- **Установленные игры Steam тоже отмечаются.** Папки библиотеки Steam (`steamapps\common`) получают отметку «в библиотеке» и значок, который игре рисует сам Steam.
- **Меню игры по правой кнопке.** *Запуск* (или *Добавить в библиотеку*, если игра ещё не добавлена), *Открыть папку*, *Коллекции*, сохранения, библиотеки апскейлеров, врапперы и *Удалить из библиотеки*, со значками. Если игра отмечена вместе с другими, действие применяется ко всем отмеченным. У ROM-игр своё меню: *Запуск*, *Открыть папку*, *Коллекции* и *Сменить эмулятор*.
- **Избранные папки.** Звезда после поля пути добавляет текущую папку в избранное; стрелка в конце поля открывает список (переименовать, переместить выше / ниже, убрать). Список общий для обеих панелей.
- **Колонки режимов.** Колонки *Размер* и *Дата* заменяются одной колонкой, зависящей от активного режима: *Враппер*, *Эмулятор*, *DLSS* или *Наличие* / *Бэкап*. По каждой можно сортировать щелчком по заголовку, а ширина колонок подбирается автоматически.
- **Подсчёт размера папок можно отменить.** Пока размеры считаются, нижняя кнопка *Library* превращается в *Отменить подсчёт*.
- **Окно не зависает при перемещении.** Прогресс берётся по реально записанным байтам, а карточки игр, которые не переносятся, можно открывать и сохранять прямо во время переноса (запись в Steam откладывается до его конца).
- **Быстрый поиск по буквам в выпадающих списках:** наберите буквы, чтобы перейти к первому подходящему пункту.

### Коллекции Steam

В окне Library справа от кнопки *Фильтр* находится выпадающий список коллекций (как в Steam): *Все коллекции*, *Избранное*, *Скрытые*, ваши коллекции с числом игр и *Без категории*; пункт *Группировать по коллекциям* раскладывает игры блоками с заголовком коллекции. По правой кнопке пункт *Коллекции* открывает окно с галочками для одной или всех отмеченных игр (квадрат означает, что в коллекции только часть игр).

Кнопка **Коллекции** в главном окне позволяет заранее выбрать коллекции для новых игр (они подставляются в каждую карточку, в том числе при автоимпорте), а кнопка в карточке игры (см. скриншот ниже) задаёт их для одной игры. Для уже добавленных игр галочки применяет нижняя кнопка *Сменить коллекции (N)*. Для записи программа закрывает Steam, обновляет `localconfig.vdf` и `cloud-storage-namespace-1.json` и запускает Steam снова; перед этим копии обоих файлов сохраняются (хранятся 10 последних). Динамические коллекции пропускаются, потому что их строит сам Steam.

### Редактирование библиотеки

Редактирование Non-Steam игр, ROM-ов и лицензионных игр Steam (обложки, параметры запуска). Автоматическое и ручное резервное копирование и восстановление `shortcuts.vdf` (файл, в котором хранится библиотека сторонних игр). Режим перезапуска Steam в настройках: **автоматически** (программа сама закрывает и запускает Steam) или **вручную** (вы сами решаете, когда перезапустить Steam, а программа корректно запишет `shortcuts.vdf` после его закрытия).

### Удаление игр из библиотеки

Кнопка **Удалить из библиотеки** (корзина) появляется между панелями, когда не включён ни один режим между ними (ROMs, Wrappers, Библиотеки, Сохранения, Коллекции) и отмечены только уже добавленные игры. То же действие — последний пункт меню игры по правой кнопке в панелях и меню плитки в Library (для одной игры или для всех отмеченных). После подтверждения программа закрывает Steam, если он запущен, делает резервную копию `shortcuts.vdf`, удаляет ярлыки игр из всех профилей Steam, подчищает остатки (обложки, hero, логотип, широкую обложку, иконку, данные об источниках обложек) и запускает Steam снова. Файлы игр не затрагиваются.

- **Shift + щелчок удаляет игру и с диска.** Пока Shift нажат, кнопка становится красной. В подтверждении перечислены папки, которые будут удалены. Игры, установленные инсталлятором, сначала удаляются их собственным деинсталлятором (программа ждёт, пока вы завершите удаление); если он отменён, игра остаётся в библиотеке. Небезопасные папки (корень диска, ссылка, Windows, Program Files, папки пользователя, папка Steam, корень панели или папка, в которой лежит другая игра библиотеки) не удаляются никогда. Файлы удаляются безвозвратно, в Корзину они не попадают.
- **Установленные игры Steam** (`steamapps\common`) ярлыка не имеют и удаляются только самим Steam, поэтому программа не предлагает для них удаление.

### Ещё

- Настройка **«Открывать при запуске»**: файловые панели или окно Library. Колонки списков подстраиваются под содержимое автоматически.
- Шесть языков интерфейса: Русский, English, 简体中文, Español, Português (Brasil), Deutsch; можно добавлять свои языковые файлы.
- Быстрый запуск и плавная работа с большими библиотеками: списки и плитки строятся порциями, прокрутка не подвисает, повторный старт ускоряется кешем скомпилированных блоков.
- Длинные подсказки переносятся в компактное окошко, значки рисуются точно по пикселям при любом масштабе экрана.
- Телеметрии нет.

## Системные требования

- Windows 10 или 11
- Windows PowerShell 5.1 (только при запуске `.ps1`)
- Установленный Steam (хотя бы один раз запущенный)
- **Права администратора**
- Интернет: для поиска игр, обложек, баз сохранений и скачивания апскейлеров
- Необязательно, но рекомендуется: [Steam Web API ключ](https://steamcommunity.com/dev/apikey), а для выбора пользовательских обложек настоятельно рекомендуется [SteamGridDB API ключ](https://www.steamgriddb.com/profile/preferences)
- Для ROM-архивов: 7-Zip (программа может предложить скачать)

## Установка

### Готовый exe
1. Скачайте `Steam Commander.exe` со страницы [Releases](../../releases)
2. Запустите (программа запросит права администратора)

### Скрипт
```powershell
# PowerShell от имени администратора
powershell -ExecutionPolicy Bypass -File .\src\Steam_Commander.ps1
```

### Сборка exe
```powershell
Install-Module ps2exe -Scope CurrentUser   # один раз
.\build\build.ps1
```
Результат: `dist\Steam Commander.exe`.

## Первоначальная настройка

1. Откройте **Настройки** и укажите папку Steam и профиль `userdata`
2. *(По желанию)* Добавьте Steam Web API и SteamGridDB API ключи
3. При необходимости скачайте библиотеки апскейлеров, обновите базу сохранений и выберите общую папку для резервных копий сохранений
4. Для ROM-ов добавьте профили эмуляторов с указанием exe
5. Для запуска через Virtual Desktop и подобные программы проверьте пути в разделе *Врапперы*
6. Выберите режим перезапуска Steam: автоматический или ручной

> При записи в `shortcuts.vdf` Steam должен быть закрыт: в автоматическом режиме программа закроет его и запустит снова. Перед операцией закройте игры и дождитесь синхронизации Steam.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Двойной щелчок / **Enter** | Открыть карточку игры |
| **Space** | Размер папок отмеченных игр, а также проверка возможности переноса этих игр между панелями |
| **Ctrl+A** | Выбрать все папки и файлы в панели; в окне Library — отметить все видимые игры |
| **Esc** | Закрыть карточку игры или окно |
| **Alt+Shift+Enter** | Размер всех папок панели |
| **F5** | Обновить панели / окно библиотеки |
| **Shift** + щелчок по *Удалить из библиотеки* | Убрать игру из библиотеки и удалить её папку с диска |
| Буквы в открытом выпадающем списке | Переход к первому пункту, который начинается с них (**Enter** или щелчок выбирает его) |
| **Delete** в списке избранного | Убрать выбранную папку из избранного |

## Где хранятся данные

| Что | Где |
|---|---|
| Настройки, профили эмуляторов | `%APPDATA%\Steam Commander` |
| Избранные папки | `config.ini` |
| База игр Steam | `%APPDATA%\Steam Commander\steam_apps_db.json` |
| Библиотеки апскейлеров | `%APPDATA%\Steam Commander` |
| База сохранений (Ludusavi) | `%APPDATA%\Steam Commander\saves` |
| Резервные копии сохранений | папка, выбранная в настройках (по умолчанию `%APPDATA%\Steam Commander\saves\backups`) |
| Утилиты для WebP (libwebp), при необходимости ffmpeg | `%APPDATA%\Steam Commander\libwebp`, `%APPDATA%\Steam Commander\ffmpeg` |
| Кеш скомпилированных блоков | `%LOCALAPPDATA%\SteamCommander\typecache` |
| Языковые файлы | `%APPDATA%\Steam Commander\lang` |
| Списки дисков m3u | `%APPDATA%\Steam Commander\m3u` |
| Резервные копии `shortcuts.vdf` | папка `backups` рядом с exe |
| Резервные копии файлов коллекций | `backups\collections` (10 последних) |
| Временные файлы | `%TEMP%\SteamCommander` |
| Ярлыки и обложки Steam | `Steam\userdata\<id>\config\` |

Ключи API хранятся в открытом виде в `config.ini`, не передавайте этот файл.

## Конфиденциальность и сеть

Телеметрии нет. Программа обращается только к:

- `store.steampowered.com`, `api.steampowered.com`, `*.steamstatic.com`, `steamcdn-a.akamaihd.net` (данные и обложки Steam)
- `api.steamcmd.net`
- `www.steamgriddb.com` и его CDN (обложки, при наличии ключа)
- `raw.githubusercontent.com` (свежая база сохранений Ludusavi, только по кнопке обновления) и `github.com`
- источникам библиотек апскейлеров DLSS Swapper
- `storage.googleapis.com` (утилиты libwebp для WebP, один раз), `www.7-zip.org` (7-Zip для архивов, по запросу), `www.gyan.dev` и `github.com` (ffmpeg, только если потребуется для WebM-превью)
- сервисам лаунчеров (GOG, Ubisoft, Microsoft Store) для названий и обложек импортируемых игр

## Известные ограничения

- Для новых или малоизвестных игр обложки Steam могут отсутствовать: помогает поиск по базам SteamGridDB
- Сопоставление названий эвристическое; индикаторы уверенности подсказывают, когда данные нужно проверить вручную
- Импорт из лаунчеров зависит от формата данных конкретного лаунчера
- Поиск сохранений опирается на базу Ludusavi и эвристику: для редких игр путь, возможно, придётся подтвердить вручную
- Анимированные обложки декодируются в фоне, поэтому тяжёлые файлы начинают играть не сразу
- Коллекции Steam записываются только при закрытом Steam; динамические коллекции не поддерживаются
- Установленные игры Steam программа удалить не может: для этого используйте Steam. Удаление папки игры по Shift необратимо
- Только Windows
